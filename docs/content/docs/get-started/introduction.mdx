Rollipop is a React Native build toolkit powered by [Rolldown](https://rolldown.rs/).

- **Module resolution**: Standard Node package resolution and Yarn PnP support, without Haste.
- **Development server**: HMR, Fast Refresh, error symbolication, source maps, and React Native DevTools.
- **Bundling**: Tree-shaking, file-system caching, and in-memory caching.
- **Plugins**: Rolldown's Rollup-compatible plugin API with React Native hooks.
- **CLI integration**: `start` and `bundle` commands registered through `react-native.config.js`.
- **TypeScript**: Typed configuration, plugins, and programmatic APIs.

See [Quick Start](/docs/get-started/quick-start) for installation.
