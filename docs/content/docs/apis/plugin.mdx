title: Plugin API
---

Rollipop extends [Rolldown's plugin API](https://rolldown.rs/apis/plugin-api/) with configuration, dev-server, and DevTools hooks.

## Plugins Config

Install plugins as `devDependencies` and add them to `plugins`:

```ts title="rollipop.config.ts"
import foo from 'rollipop-plugin-foo';
import bar from 'rollipop-plugin-bar';
import baz from 'rollipop-plugin-baz';

export default defineConfig({
  plugins: [foo(), bar(), baz()],
});
```

`false`, `null`, and `undefined` entries are ignored. Promises are awaited and nested plugin arrays are flattened, so presets can return arrays:

```ts title="framework-plugin.ts"
import foo from 'rollipop-plugin-foo';
import bar from 'rollipop-plugin-bar';
import baz from 'rollipop-plugin-baz';

export default function framework() {
  return [foo(), bar(), baz()];
}
```

```ts title="rollipop.config.ts"
import framework from 'rollipop-plugin-framework';

export default defineConfig({
  plugins: [framework()],
});
```

## Universal Hooks

Rollipop supports Rolldown's public plugin hooks.

## Rollipop Specific Hooks

### `config`

- **Kind:** `async`, `sequential`

Receives defaults merged with user config and preceding plugins' changes. Return partial config to merge, or mutate the received object. The `plugins` field is excluded from this hook; use a preset array to add plugins.

```ts
export default function myPlugin() {
  return {
    name: 'my-plugin',
    config: {
      resolve: {
        alias: {
          '@': '/src',
        },
      },
    },
  };
}
```

Return partial config from a function:

```ts
export default function myPlugin() {
  return {
    name: 'my-plugin',
    config(config) {
      // Return partial config to merge
      return {
        resolve: {
          alias: {
            '@': '/src',
          },
        },
      };
    },
  };
}
```

Or mutate the config directly:

```ts
export default function myPlugin() {
  return {
    name: 'my-plugin',
    config(config) {
      // Directly override existing config
      config.resolve.alias = {
        ...config.resolve.alias,
        '@': '/src',
      };
    },
  };
}
```

### `configResolved`

- **Kind:** `async`, `parallel`

Called after the Rollipop config is resolved. Use this hook to read and store the final resolved config. Do not mutate the config inside this hook.

```ts
export default function myPlugin() {
  let config: ResolvedConfig;

  return {
    name: 'my-plugin',
    configResolved(resolvedConfig) {
      // Store the config for use in other hooks
      config = resolvedConfig;
    },
  };
}
```

### `configureServer`

- **Kind:** `async`, `sequential`

Receives the `DevServer` instance. Use `server.middlewares.use` for Express/Connect-style middleware, or access the Fastify and WebSocket servers directly.

---

**Adding Middleware**

Return a function to register middleware after the built-in stack:

```ts
export default function myPlugin() {
  return {
    name: 'my-plugin',
    configureServer(server) {
      // Add middleware before built-in middlewares
      server.middlewares.use((req, res, next) => {
        console.log('Early middleware');
        next();
      });

      // Return a function to add middleware after built-in middlewares
      return () => {
        server.middlewares.use((req, res, next) => {
          console.log('Late middleware');
          next();
        });
      };
    },
  };
}
```

---

**Accessing Server Instances**

```ts
export default function myPlugin() {
  return {
    name: 'my-plugin',
    configureServer(server) {
      // Access the resolved config
      console.log('Resolved config:', server.config);

      // Access the Fastify instance
      server.instance.get('/custom-route', async (request, reply) => {
        return { hello: 'world' };
      });

      // Access the message WebSocket server
      server.message.broadcast('custom-event', { data: 'hello' });

      // Access the events WebSocket server
      server.events.reportEvent({ type: 'custom-event', message: 'hello' });

      // Access the HMR WebSocket server
      server.hot.sendAll('custom-hmr', { message: 'Hey!' });
    },
  };
}
```

**Note:** The `configureServer` hook runs when creating a dev server with `runServer` or the
`start` command. It does not run for `runBuild` or the `bundle` command.

### `devtools`

Add UI and tooling to the dashboard with [`devtools.setup(context)`](https://devtools.vite.dev/kit/devtools-plugin.html). The context also provides `rollipopConfig` and `rollipopServer`.

Register an iframe dock for a UI served by the plugin:

```ts title="plugin.ts"
import type { Plugin } from 'rollipop';

export default function inspectorPlugin(): Plugin {
  return {
    name: 'rollipop-plugin-inspector',
    devtools: {
      setup(context) {
        context.docks.register({
          id: 'inspector',
          title: 'Inspector',
          icon: 'ph:magnifying-glass-duotone',
          type: 'iframe',
          url: '/__rollipop/inspector/',
        });
      },
    },
  };
}
```

`devtools.setup` runs sequentially in plugin order during server creation. Set `capabilities.dev: false` to skip it; a capability object containing any `false` value also skips setup. `capabilities.build` is not used by standalone Rollipop builds.

#### Adapting a Devframe

Wrap a [Devframe](https://devfra.me/) definition with `createPluginFromDevframe`:

```ts title="plugin.ts"
import { createPluginFromDevframe } from '@rollipop/devtools-kit/node';
import { defineDevframe } from 'devframe';
import type { Plugin } from 'rollipop';

const inspectorDevframe = defineDevframe({
  id: 'inspector',
  name: 'Inspector',
  version: '1.0.0',
  packageName: 'rollipop-plugin-inspector',
  importMetaUrl: import.meta.url,
  homepage: 'https://example.com/rollipop-plugin-inspector',
  description: 'Inspect project state from the Rollipop dashboard.',
  icon: 'ph:magnifying-glass-duotone',
  clientAssets: './client/dist',
  capabilities: {
    dev: true,
    build: false,
  },
  async setup(context) {
    await context.scope('inspector').rpc.sharedState('summary', {
      initialValue: { files: 0 },
    });
  },
});

export default function inspectorPlugin(): Plugin {
  return createPluginFromDevframe(inspectorDevframe, {
    base: '/__rollipop/inspector/',
  });
}
```

The adapter serves `clientAssets` and adds a dashboard tab. Use `dock` to customize the tab or `setup` for additional initialization.

Adapter options:

| Option         | Type                                    | Default                                                              |
| -------------- | --------------------------------------- | -------------------------------------------------------------------- |
| `name`         | `string`                                | `devframe:<id>`                                                      |
| `base`         | `string`                                | The definition's `basePath`, or `/__<id>/`.                          |
| `dock`         | iframe dock metadata overrides          | Derived from the definition; cannot override `id`, `type`, or `url`. |
| `capabilities` | `DevToolsPluginOptions['capabilities']` | The definition's capabilities.                                       |
| `setup`        | `(context) => void \| Promise<void>`    | —; runs after the Devframe is installed.                             |

## Plugin Ordering

Rolldown hooks can use the object form with `order: 'pre'` or `order: 'post'` to adjust the order of
that hook. Set `order` on the hook, not on the plugin object. Rollipop-specific `config` and
`configureServer` hooks run in the order of the `plugins` array.

```ts title="plugins.ts"
import type { Plugin } from 'rollipop';

export function prePlugin(): Plugin {
  return {
    name: 'pre-plugin',
    transform: {
      order: 'pre',
      handler(code, id) {
        console.log('First transform:', id);
        return code;
      },
    },
  };
}

export function postPlugin(): Plugin {
  return {
    name: 'post-plugin',
    transform: {
      order: 'post',
      handler(code, id) {
        console.log('Last transform:', id);
        return code;
      },
    },
  };
}
```

```ts title="rollipop.config.ts"
import { prePlugin, postPlugin } from './plugins';

export default defineConfig({
  // Hook order takes priority over array position for the transform hooks.
  plugins: [postPlugin(), prePlugin()],
});
```

## Hook Filters

Use [hook filters](https://rolldown.rs/apis/plugin-hook-filters) to run hooks only for matching modules:

```ts title="my-plugin.ts"
export default function myPlugin() {
  const jsFileRegex = /\.js$/;

  return {
    name: 'my-plugin',
    // Example: only call transform for .js files
    transform: {
      filter: {
        id: jsFileRegex,
      },
      handler(code, id) {
        return {
          code: transformCode(code),
          map: null,
        };
      },
    },
  };
}
```

## Client-Server Communication

### Server to Client

Broadcast events with `server.hot.sendAll`:

```ts
{
  name: 'my-plugin',
  configureServer(server) {
    setInterval(() => {
      if (server.hot.clients.size === 0) {
        this.debug('No clients connected, skipping sending message');
        return;
      } else {
        this.debug('Sending message to clients...');
      }

      server.hot.sendAll('my-custom:from-server', { message: 'Hello from server' });
    }, 5_000);
  }
}
```

Listen with `import.meta.hot.on`:

```ts
if (import.meta.hot) {
  import.meta.hot.on('my-custom:from-server', (data) => {
    console.log(data.message); // Hello from server
  });
}
```

### Client to Server

Send events with `import.meta.hot.send`:

```ts
if (import.meta.hot) {
  import.meta.hot.send('my-custom:from-client', { msg: 'Hey!' });
}
```

Listen with `server.hot.on`:

Client event names must not use the reserved WebSocket and EventEmitter names `close`,
`connection`, `error`, `headers`, `listening`, `wsClientError`, `newListener`, or `removeListener`.

```ts
{
  name: 'my-plugin',
  configureServer(server) {
    server.hot.on('my-custom:from-client', (data) => {
      console.log('Message from client:', data.msg) // Hey!
    });
  },
}
```

### Global Message Handler

Register a global handler with `setCustomHMRHandler`. It replaces any previous handler and runs only when the development runtime is initialized:

```ts
import type { HMRCustomMessage } from 'rollipop';
import { setCustomHMRHandler } from 'rollipop/runtime';

setCustomHMRHandler((socket: WebSocket, message: HMRCustomMessage) => {
  console.log('Received custom HMR message:', message);

  switch (message.type) {
    case 'my-custom:from-server':
      console.log('Payload:', message.payload);
      break;
  }
});
```

**Signature**

`setCustomHMRHandler(handler: HMRCustomHandler)`

**Types:**

```ts
type HMRCustomHandler = (socket: WebSocket, message: HMRCustomMessage) => void;

type HMRCustomMessage = {
  type: string;
  payload: unknown;
};
```
