---
title: Custom Command
---

Add keyboard shortcuts to the dev server terminal with `commands`.

## Configuration

```ts title="rollipop.config.ts"
import { defineConfig } from 'rollipop';

export default defineConfig({
  commands: [
    {
      key: 'a',
      description: 'Clear console',
      handler() {
        console.clear();
      },
    },
  ],
});
```

## Command Options

| Property      | Type                                        | Required | Description                                                                                |
| ------------- | ------------------------------------------- | -------- | ------------------------------------------------------------------------------------------ |
| `key`         | `string`                                    | Yes      | The keyboard key to trigger the command (e.g., 'a', 'b', 'c')                              |
| `description` | `string \| (() => string)`                  | Yes      | A description, or a function that returns it when the command list is printed              |
| `handler`     | `(this: InteractiveCommandContext) => void` | Yes      | The function to execute; `this.server` and `this.logger` provide the dev server and logger |
| `shift`       | `boolean`                                   | No       | If `true`, requires Shift key to be pressed with the key                                   |

Use a single lowercase character for `key`. The built-in shortcuts `r`, `j`, `d`, and `Shift + d`
are reserved. Custom commands run in the interactive terminal started by `rollipop start`;
non-interactive environments do not enable keyboard shortcuts.

## Shift Modifier

Use `shift: true` to bind `Shift + a` separately from `a`:

```ts title="rollipop.config.ts"
export default defineConfig({
  commands: [
    {
      key: 'a',
      description: 'My custom command 1',
      handler() {
        console.log('My custom command 1');
      },
    },
    {
      key: 'a',
      shift: true,
      description: 'My custom command 2',
      handler() {
        console.log('My custom command 2');
      },
    },
  ],
});
```
