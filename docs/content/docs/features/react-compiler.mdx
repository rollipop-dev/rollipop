---
title: React Compiler
---

Enable React Compiler to optimize React components and hooks.

## Setup

React Compiler is disabled by default. Pass an empty object to opt in with Rollipop's defaults:

```ts title="rollipop.config.ts"
import { defineConfig } from 'rollipop';

export default defineConfig({
  transform: {
    jsx: {
      compiler: {},
    },
  },
});
```

With the empty object form, Rollipop skips files whose module id matches `/node_modules/`.

## Configuration

`transform.jsx.compiler` accepts rolldown's React Compiler options.

| Property          | Type                                           | Description                                                               |
| ----------------- | ---------------------------------------------- | ------------------------------------------------------------------------- |
| `include`         | `Array<string \| RegExp>`                      | File patterns to compile. Empty means all files that enter the transform. |
| `exclude`         | `Array<string \| RegExp>`                      | File patterns to skip. Overrides Rollipop's default exclude list.         |
| `compilationMode` | `'infer' \| 'syntax' \| 'annotation' \| 'all'` | Which functions to compile.                                               |
| `panicThreshold`  | `'none' \| 'critical_errors' \| 'all_errors'`  | How strictly compilation failures should be reported.                     |
| `target`          | `'17' \| '18' \| '19'`                         | React runtime version target.                                             |
| `noEmit`          | `boolean`                                      | Report diagnostics without emitting transformed code.                     |

### Additional Compiler Options

| Option                   | Type                                              | Default | Description                                      |
| ------------------------ | ------------------------------------------------- | ------- | ------------------------------------------------ |
| `outputMode`             | `'client' \| 'ssr' \| 'lint'`                     | —       | Compiler output mode.                            |
| `ignoreUseNoForget`      | `boolean`                                         | `false` | Compile functions with opt-out directives.       |
| `flowSuppressions`       | `boolean`                                         | `true`  | Treat Flow suppression comments as opt-outs.     |
| `enableReanimated`       | `boolean`                                         | `false` | Enable Reanimated support in the compiler.       |
| `isDev`                  | `boolean`                                         | `false` | Compiler development mode.                       |
| `filename`               | `string`                                          | —       | Source file name for diagnostics.                |
| `eslintSuppressionRules` | `string[]`                                        | —       | ESLint suppressions that opt functions out.      |
| `customOptOutDirectives` | `string[]`                                        | —       | Additional opt-out directives.                   |
| `gating`                 | `{ source: string; importSpecifierName: string }` | —       | Import a gate and emit gated compiled functions. |
| `dynamicGating`          | `{ source: string }`                              | —       | Dynamic gating import source.                    |

`compilationMode` defaults to `'infer'`, `panicThreshold` to `'none'`, `target` to `'19'`, and `noEmit` to `false`.

Explicit `transform.swc.native.react.compiler` options override `transform.jsx.compiler`. `enableReanimated` does not enable the separate [worklet transform](/docs/experimental/reanimated-worklets).

### Excluding dependencies

A custom `exclude` replaces the default. Include `/node_modules/` to keep dependencies excluded:

```ts title="rollipop.config.ts"
export default defineConfig({
  transform: {
    jsx: {
      compiler: {
        exclude: [/node_modules/, /vendor/],
      },
    },
  },
});
```

## Manual Memoization

The compiler can replace memoization used only for render performance. Keep memoization required for observable behavior, non-render work, or custom equality checks.
