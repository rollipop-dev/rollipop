<Callout type="warn">
  Module Federation is an early implementation. Its API and bundle layout may change between
  releases. See [Limitations](#limitations) for supported roles and imports.
</Callout>

[`@rollipop/plugin-module-federation`](https://github.com/rollipop-dev/rollipop/tree/main/packages/plugin-module-federation) shares modules and dependencies between React Native bundles.

## Installation

```sh
yarn add -D @rollipop/plugin-module-federation@beta
yarn add @module-federation/runtime
```

## Roles

A single Rollipop config takes **exactly one role**. Defining both `remotes` and `exposes` throws.

| Role   | Option    | Purpose                                                |
| ------ | --------- | ------------------------------------------------------ |
| Host   | `remotes` | Loads remote modules and provides shared dependencies. |
| Remote | `exposes` | Exposes modules to hosts.                              |

Split a host and a remote into two configs and run them as separate Rollipop processes.

## Host

The host declares the remotes it consumes and the dependencies it shares.

The script loader below uses the native `ScriptManager` supplied by the
[`module-federation` example](https://github.com/rollipop-dev/rollipop/blob/main/examples/module-federation/mf-script-loader.ts).
Provide a loader for your own app's native implementation.

```ts title="rollipop.host.config.ts"
import { federation } from '@rollipop/plugin-module-federation';
import { defineConfig } from 'rollipop';

export default defineConfig({
  entry: 'src/host/index.ts',
  plugins: [
    federation({
      name: 'host_app',
      remotes: {
        remote_app: 'remote_app@http://localhost:8082/index.bundle?platform=ios',
      },
      shared: {
        react: { singleton: true, eager: true, requiredVersion: '19.2.3' },
        'react-native': { singleton: true, eager: true, requiredVersion: '0.84.1' },
      },
      runtime: {
        implement: `
          const NativeScriptManager = globalThis.nativeModuleProxy.ScriptManager;
          globalThis.__rollipop_script_loader__ = {
            async loadScript({ scriptId, url }) {
              await NativeScriptManager.loadScript(scriptId, { url });
            },
          };
        `,
      },
    }),
  ],
});
```

Consume a remote with a dynamic import:

```ts
const RemoteNavigator = React.lazy(() =>
  import('remote_app/RemoteNavigator').then((m) => ({ default: m.default ?? m })),
);
```

Render the imported component inside a React `Suspense` boundary while it loads.

The `remotes` key is the import alias and may differ from the remote container's name. For example,
`remotes: { catalog: 'catalog_app@https://example.com/catalog.bundle' }` is consumed as
`import('catalog/RemoteNavigator')`. The object form is
`{ catalog: { name: 'catalog_app', entry: 'https://example.com/catalog.bundle' } }`.

Failed remote loads are thrown to the nearest React Error Boundary. In its retry action,
reload the remote before resetting the boundary:

```ts
import { retryRemote } from '@rollipop/plugin-module-federation/runtime';

await retryRemote('remote_app/RemoteNavigator');
resetErrorBoundary();
```

Pass the import alias and exposed path to `retryRemote`. Failed retries reject.

## Remote

The remote declares the modules it exposes.

```ts title="rollipop.remote.config.ts"
import { federation } from '@rollipop/plugin-module-federation';
import { defineConfig } from 'rollipop';

export default defineConfig({
  entry: 'src/remote/index.ts',
  plugins: [
    federation({
      name: 'remote_app',
      exposes: {
        './RemoteNavigator': './src/remote/exposed/RemoteNavigator.tsx',
      },
      shared: {
        react: { singleton: true, requiredVersion: '19.2.3' },
        'react-native': { singleton: true, requiredVersion: '0.84.1' },
      },
    }),
  ],
});
```

Remotes support HMR when served by the development server.

## Configuration

| Option              | Type                                                                           | Default / requirement                                                                        |
| ------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `name`              | `string`                                                                       | Required, non-empty container name.                                                          |
| `remotes`           | `Record<string, string \| ModuleFederationRemoteConfig>`                       | `{}`; host remote aliases.                                                                   |
| `exposes`           | `Record<string, string>`                                                       | `{}`; keys must start with `./`, values resolve from the project root.                       |
| `shared`            | `string[] \| Record<string, string \| ModuleFederationSharedDependencyConfig>` | `[]`; installed package versions are detected. A string object value sets `requiredVersion`. |
| `shareStrategy`     | `'version-first' \| 'loaded-first'`                                            | `'version-first'`                                                                            |
| `runtime.implement` | `string`                                                                       | Host loader source, injected before modules run.                                             |

Remote strings accept `name@url` or a plain URL, which uses the alias as the container name. The object form is `{ name, entry, type?: 'var' }`; `type` defaults to `'var'`.

Shared dependency objects accept `requiredVersion?: string`, `singleton?: boolean`, and `eager?: boolean`. Both booleans default to `false`.

```ts
federation({
  name: 'host_app',
  remotes: { catalog: { name: 'catalog_app', entry: 'https://example.com/catalog.bundle' } },
  shared: ['react', 'react-native'],
  shareStrategy: 'loaded-first',
});
```

## Script loader contract

Register a loader on `globalThis.__rollipop_script_loader__`. Its `loadScript` method must download and evaluate the bundle before resolving:

```ts
export interface ModuleFederationScriptLoader {
  loadScript(args: { scriptId: string; url: string; parentUrl?: string }): Promise<void>;
}
```

## Limitations

- A config cannot define both `remotes` and `exposes`; bidirectional and chained federation are not supported.
- Remote imports support default React component exports.
- Shared dependency subpaths (such as `react/jsx-dev-runtime`) are bundled separately in each remote.

See [`examples/module-federation`](https://github.com/rollipop-dev/rollipop/tree/main/examples/module-federation) for a working RN 0.84 host + remote setup with a Kotlin/JNI and Obj-C++ script loader.
