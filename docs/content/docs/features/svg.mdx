---
title: SVG Support
---

SVG support is provided by the [`@rollipop/plugin-svg`](https://github.com/rollipop-dev/rollipop/tree/main/packages/plugin-svg) plugin, which transforms `.svg` files into React components using `@svgr/core`.

## Pre-requisites

Install the [react-native-svg](https://github.com/software-mansion/react-native-svg#installation) native module.

## Installation

```sh
yarn add -D @rollipop/plugin-svg@beta
```

## Usage

```ts title="rollipop.config.ts"
import { svg } from '@rollipop/plugin-svg';
import { defineConfig } from 'rollipop';

export default defineConfig({
  plugins: [svg()],
});
```

`svg()` takes no options.

With the plugin enabled, `.svg` imports resolve to React components. Otherwise, they resolve to static assets.

## TypeScript

Declare SVG modules in a file included by your `tsconfig.json`:

```ts title="svg.d.ts"
declare module '*.svg' {
  import type { ComponentType } from 'react';
  import type { SvgProps } from 'react-native-svg';

  const component: ComponentType<SvgProps>;
  export default component;
}
```
