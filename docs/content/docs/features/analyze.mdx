---
title: Bundle Analysis
---

Generate an interactive report of bundle contents and module sizes.

## Usage

```ts title="rollipop.config.ts"
import { defineConfig } from 'rollipop';

export default defineConfig({
  analyzer: {
    enabled: true,
  },
});
```

Standalone builds write `analyze-data.json` and `report.html` to the bundle output directory.
The dev server and builds without an output directory write `.rollipop/analyze/<bundler-id>.json` and `.rollipop/analyze/<bundler-id>.html`.

You can also upload the JSON data file to the [Analyzer](https://leegeunhyeok.github.io/rolldown-analyzer) web app.

## Options

### enabled

- **Type:** `boolean`
- **Default:** `false`

Enable bundle analysis.

### analyzeFile

- **Type:** `string`
- **Default:** `'analyze-data.json'`

Output filename for the analysis data in build mode.

### reportFile

- **Type:** `string`
- **Default:** `'report.html'`

Output filename for the generated HTML report in build mode.

### autoOpen

- **Type:** `boolean`
- **Default:** `false`

Automatically open the generated report in the browser after a standalone build completes.
This option does not open reports automatically while the dev server is running.

```ts
export default defineConfig({
  analyzer: {
    enabled: true,
    autoOpen: true,
  },
});
```
