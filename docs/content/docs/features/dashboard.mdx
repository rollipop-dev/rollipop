Rollipop includes a built-in dashboard for inspecting the development server from the browser.

![Rollipop dashboard overview](/dashboard.png)

Run `rollipop start`, then open [localhost:8081/dashboard](http://localhost:8081/dashboard).

## Features

- **Instances**: Inspect active bundler instances, targets, build options, bundle URLs, and the latest build status
- **Devices**: View connected React Native DevTools targets
- **Bundles**: Preview large generated bundles by position without rendering the entire file
- **Analyze**: Open bundle analysis reports when the analyzer is enabled
- **Build Logs**: Inspect build logs by bundler instance and filter by log level
- **Actions**: Reload connected clients, reset the transform cache, and clear stored build summaries and logs

## Devframe Integration

The dashboard uses [Devframe](https://devfra.me/) under `/__rollipop/`. Install `@devframes/agentic` to also enable [MCP Server](/docs/features/mcp); the dashboard does not require it.

| Purpose             | Endpoint                        |
| ------------------- | ------------------------------- |
| Connection metadata | `/__rollipop/__connection.json` |
| SSE transport       | `/__rollipop/__sse`             |
| MCP (when enabled)  | `/__rollipop/__mcp`             |
| Embedded dock UI    | `/__rollipop/embedded.js`       |

## Bundle Analysis

The Analyze tab depends on the analyzer configuration and generated report files. See [Bundle Analysis](/docs/features/analyze) for setup and options.
