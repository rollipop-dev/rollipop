title: Dev Server

The dev server supports iOS and Android with HMR, Fast Refresh, source maps, React Native DevTools, and the Rollipop dashboard.

## Usage

### Using Commands

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">```npx rollipop start```</Tab>
  <Tab value="pnpm">```pnpm rollipop start```</Tab>
  <Tab value="yarn">```yarn rollipop start```</Tab>
</Tabs>

```bash
# Start on a custom port
rollipop start --port 3000

# Reset cache on start
rollipop start --reset-cache
```

HTTPS is not supported yet. Although the CLI accepts `--https`, `--key`, and `--cert`, starting with `--https` fails.

See [CLI Commands](/docs/get-started/cli-commands) for all options.

### Using Bundler API

```ts
import * as Rollipop from 'rollipop';

const config = await Rollipop.loadConfig({
  mode: 'development',
  context: { command: 'start' },
});

const server = await Rollipop.runServer(config, {
  port: 8081,
  host: 'localhost',
});

// Listen to HMR client events
server.on('client.connected', ({ client }) => {
  console.log('Client connected:', client.id);
});

server.on('client.disconnected', ({ client }) => {
  console.log('Client disconnected:', client.id);
});

console.log('Dev server running at:', server.instance.listeningOrigin);
```

See [Bundler API](/docs/apis/bundler) for more details.

## Fast Refresh

Use `transform.jsx.refresh.include` and `exclude` to select modules for Fast Refresh. Both accept a string, `RegExp`, or an array of either.

Defaults are `[/\.[tj]sx?(?:$|\?)/]` for `include` and `[/node_modules/]` for `exclude`. Custom values replace those defaults; empty arrays remove the corresponding filter.

```ts title="rollipop.config.ts"
import { defineConfig } from 'rollipop';

export default defineConfig({
  transform: {
    jsx: {
      refresh: {
        include: [/\.[tj]sx?(?:$|\?)/],
        exclude: [/node_modules/, /generated/],
      },
    },
  },
});
```

The dev server manages Refresh activation. Set `dev.hmr: false` to disable HMR and Fast Refresh; `transform.jsx.refresh: false` does not disable the server's Refresh integration.

## Keyboard Shortcuts

| Key         | Action                            |
| ----------- | --------------------------------- |
| `r`         | Reload connected apps.            |
| `j`         | Open React Native DevTools.       |
| `d`         | Open the developer menu.          |
| `Shift + d` | Toggle automatic DevTools launch. |

Shortcuts require an interactive terminal. Use `--no-interactive` to disable them or [`commands`](/docs/features/custom-command) to add your own.

## Plugin Integration

Plugins can send and receive WebSocket events through the dev server. See [Client-Server Communication](/docs/apis/plugin#client-server-communication).
