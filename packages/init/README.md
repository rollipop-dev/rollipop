# @rollipop/init

Run from a React Native project root:

```bash
yarn dlx @rollipop/init@beta
yarn install
```

Adds the matching Rollipop version to `devDependencies` and registers its commands in `react-native.config.js`. Existing custom command configurations may require a manual update.

See [Quick Start](https://rollipop.dev/docs/get-started/quick-start).
