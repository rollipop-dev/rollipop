# Expo SDK 58

An Expo Router app using `@rollipop/expo` with React Native 0.88, React 19.3, Reanimated 4.7.1, and Worklets 0.13.0.

The integration is enabled by one entry in `app.json`:

```json
{
  "expo": {
    "plugins": ["expo-router", "@rollipop/expo"],
    "experiments": {
      "typedRoutes": true,
      "reactCompiler": true
    }
  }
}
```

No custom Metro or Babel configuration is needed. See [the adapter's release status and limits](../../packages/expo/README.md) before using it in production.

From the repository root:

```sh
yarn install --immutable
yarn build:all
yarn workspace rollipop-example-expo-58 start --go
```

Use the running iOS Simulator to open the printed Expo Go URL. The home screen shows the engine/runtime, a local image, a counter, dynamic and grouped Router links, a UI-thread Worklet returning 42, an animated shared value, and a compiled component returning 42. Edit the home marker to verify Fast Refresh preserves the counter.

```sh
yarn workspace rollipop-example-expo-58 ios --configuration Release
yarn workspace rollipop-example-expo-58 android --variant release
yarn workspace rollipop-example-expo-58 export --source-maps --dump-assetmap
yarn workspace rollipop-example-expo-58 typecheck
```

Native projects are generated by Expo and ignored by Git. `eas.json` includes simulator/internal preview and production profiles. Cloud builds require the user's EAS project and signing setup.

The SDK 58 template's native Expo modules are retained to exercise autolinking and native builds. Knip's exceptions cover those native dependencies that are not imported by the small JavaScript test screen.

See the [Expo guide](../../docs/content/docs/experimental/expo.mdx) for setup and current limitations.
